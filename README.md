## 🟢 Overview

This repository houses a high-performance, single-page terminal and cybersecurity-themed portfolio design. Built completely using raw vanilla web technologies, it features high-contrast accessibility, zero heavy JavaScript library overhead, responsive mobile design, and an interactive particle background mesh.

---

## ✨ Key Features

* **Cyber Operations Theme:** Clean dark-mode aesthetics using modern system color tokens, custom CSS variables, and matrix/terminal accenting.
* **Interactive Background Canvas:** Custom vanilla JavaScript HTML5 canvas rendering an interactive particle network mesh that responds to cursor movement.
* **Terminal Interface Simulation:** Dynamic typing animation mimicking a CLI prompt startup (`whoami --verbose && cat skills.json`).
* **Fully Responsive Mobile Drawer:** Native CSS layout featuring zero-dependency, collapsible drawer navigation optimized for touch devices.
* **Integrated Form Handling:** Integrated contact form pre-configured for asynchronous payload transmissions.
* **Zero External JS Frameworks:** Built purely with semantic HTML5, native CSS3, and standard ES6 JavaScript APIs for maximum loading speeds.

---

## 🛠️ Tech Stack & Tools

* **Markup & Structure:** HTML5 (Semantic Structure & Microdata Accessibility)
* **Styling & Layout:** CSS3 (Custom Properties, Flexbox, CSS Grid)
* **Scripting & Canvas API:** Vanilla JavaScript (ES6+)
* **Fonts & Icons:** Fira Code, Space Grotesk via Google Fonts, Font Awesome v6.5.1
* **Hosting Support:** Optimized for GitHub Pages, Vercel, or Netlify
